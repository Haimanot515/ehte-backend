Ehte Backend documentation.

This document describes the Ehte backend platform, its architecture, API behavior, security practices, development workflow, deployment configuration, and operational guidelines.

Ehte is a secure platform focused on confidential reporting, public awareness, missing-person support, victim/survivor profiles, and related support services in Ethiopia.
